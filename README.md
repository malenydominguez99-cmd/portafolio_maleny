# Portafolio personal | Maleny Dominguez

## Descripción

Proyecto de desarrollo web enfocado en la creación de un portafolio personal para presentar información profesional, habilidades, proyectos y medios de contacto.

El sitio cuenta con una estructura inicial que incluye una barra de navegación, una sección de presentación personal, enlaces a redes profesionales y un menú desplegable para dispositivos móviles.

**Estado del proyecto:** En desarrollo / Incompleto.

## Objetivo

Practicar los fundamentos del desarrollo frontend mediante la creación de una página web personal, aplicando HTML y CSS para estructurar y diseñar la interfaz, así como JavaScript para incorporar interacciones básicas.

## Contexto

Proyecto personal de práctica enfocado en aplicar conocimientos de desarrollo web y explorar la construcción de un portafolio profesional.

## Pasos realizados

1. Crear la estructura principal de la página utilizando HTML5.
2. Diseñar una barra de navegación con diferentes apartados.
3. Incorporar una sección de presentación personal con fotografía.
4. Agregar enlaces a perfiles de GitHub, LinkedIn e Instagram.
5. Aplicar estilos visuales mediante CSS.
6. Integrar iconos de Font Awesome.
7. Implementar un menú desplegable para dispositivos móviles mediante JavaScript.

## Resultado

Se construyó una primera versión de la interfaz de un portafolio personal, con una sección de presentación y elementos básicos de navegación.

El proyecto quedó como una versión inicial, pendiente de completar las secciones de proyectos, información personal y contacto, así como configurar el acceso al currículum.

## Aprendizajes

- Estructuración de páginas web con HTML5.
- Diseño de interfaces con CSS3.
- Organización de elementos mediante Flexbox.
- Integración de imágenes y recursos externos.
- Uso de iconos con Font Awesome.
- Implementación de eventos con JavaScript.
- Creación de menús desplegables.
- Diseño adaptable a diferentes dispositivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
